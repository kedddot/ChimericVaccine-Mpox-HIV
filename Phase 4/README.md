# Phase IV: saved Phase I/II-only analysis

This directory holds the code for the completed revised-methodology Section IV, Steps A–G, using the frozen Phase I and II outputs. The saved Phase IV evidence is in `../Step_Outputs/Phase4/`. No Phase III, molecular-docking, MD or C-ImmSim output was used in this branch.

Read `../Handoff.md` for the evidence boundary and later integration requirements, `../PHASE_IV_RESULTS_DETAILED.md` for the current quantitative narrative, and `../PAPER_UPDATES_PHASE_IV.md` for manuscript wording and corrections. The 31-row final dossier and 155-entry numbers ledger are in `../Step_Outputs/Phase4/StepG/`. The baseline hash file in `../Step_Outputs/Phase4/` records the 1,810 frozen Phase I/II files checked during the analysis.

`STEP G/Phase4G_integratedReport.py` is the **historical generator**. Its embedded report and correction prose predates the consolidated documents and includes interpretations that have been superseded. Running it would overwrite the two short Step G redirect documents with that older prose. Do not use regenerated prose as a paper result without reconciling it against the current results narrative and saved CSVs. The script and run logs are retained to preserve the execution record.

All reported binding, processing, T-cell-recognition, B-cell and population-coverage values are predictions or calculations from saved data. They are not experimental evidence of an immune response or protection. The 42-page working-draft manuscript PDF reviewed for the paper update is excluded from the Phase IV publication set while the raw-run provenance for its old Section III claims remains unresolved.
